# Gym Tracking App

Gym Tracking App is an Android application concept for tracking workouts, nutrition, and personal fitness progress. It is designed for you who want to lose fat, gain muscle, maintain or anything else to get a balanced fitness routine.

## Features

### User

- Register, sign in, and manage personal profile information.
- Select a workout goal: lose fat, gain muscle, or maintain current condition.
- Browse the exercise library by category.
- Receive exercise suggestions based on BMI and workout goal.
- Record workout logs by set.
- Receive next-set recommendations based on the latest workout log and recent training history.
- Look up nutrition information for food products.
- Save nutrition logs.
- View workout and nutrition statistics.
- Manage workout logs and nutrition logs.
- View profile information and sign out.

### Admin

- View the user list.
- View detailed user information and workout history.
- Manage the exercise library: add, update, and delete exercises.

## Requirements

- Java Development Kit 21.
- Gradle or the Gradle Wrapper included in the project.
- Eclipse IDE or another IDE with Java/Gradle support.
- Internet connection for nutrition lookup.

## Libraries

- Gson: read and write JSON data.
- JFreeChart: render statistics charts.
- FlatLaf: UI look-and-feel support.
- JUnit 5: write and run unit tests.

## Commands

Run the application:

```powershell
.\gradlew.bat run
```

Run tests:

```powershell
.\gradlew.bat test
```

Build the project:

```powershell
.\gradlew.bat build
```
